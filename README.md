# Small discord bot

Just a small discord bot that does some stuff

You can clone this repo and do `uv sync` in your terminal to create a virtual environment and install the dependencies.

## uv

This bot uses `uv`, the python venv manager, to manage its virtual environment.
Please always use a virtual environment for python development!!!!!

[astral-sh/uv: An extremely fast Python package and project manager, written in Rust.](https://github.com/astral-sh/uv/tree/main)
